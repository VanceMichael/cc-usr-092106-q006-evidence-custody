# 涉案药品保全与抽检交接

描述查获药品从现场到送检和处置的保全关系。

## 领域资料

仓库中的 `contracts/context.schema.json` 描述基础资料格式，`fixtures/context.json` 给出可公开使用的示例。代码库只负责读取与校验这些资料，业务服务可沿用相同标识和版本约定。

当前资料反映的事实包括：

- 联合行动从仓库、车辆和快递中转点查获药品，逐件登记来源点位
- 外包装破损、温控未知的情形须如实记录，冷藏要求不明时状态标注为未知
- 公安与医保共用保全后台，封条、箱组、单盒、拍照、称量、库位与保管责任连续交接
- 抽样拆分出新的证物单元，但不改变原始查获数量，并登记剩余数量
- 开封、复封、送检、退样和依法处置须对应角色发起并经双人确认
- 扫码重复、断网、封条损坏或库位调整只产生待复核事件，不静默改写当前保管人
- 检验机构可核对完整来源，案件人员可追溯任意时点的保管人、开封原因与剩余数量

## 本地校验

运行项目自带测试即可确认样例资料可读取，且领域标识与版本字段完整。所有示例均为虚构数据，不含真实个人信息、账号或访问凭据。
