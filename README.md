# 涉案药品保全与抽检交接

描述查获药品从现场到送检和处置的保全关系。

## 领域资料

仓库中的 `contracts/context.schema.json` 描述基础资料格式，`fixtures/context.json` 给出可公开使用的示例。代码库只负责读取与校验这些资料，业务服务可沿用相同标识和版本约定。

当前资料反映的事实包括：

- 联合行动药品可同时来自仓库、车辆和快递中转点，来源分别登记
- 外包装破损、温控未知、多单位轮流查看时，抽检仍须能追溯样品来自哪一箱
- 公安与医保共用保全后台，封条、箱组、单盒、拍照、称量、库位、保管责任全程连续交接
- 抽样拆分出新证物单元，但原始查获数量不变
- 开封、复封、送检、退样、依法处置按角色授权且双人确认
- 扫码重复、断网、封条损坏、库位调整只产生待复核事件，不静默改写保管人
- 冷藏要求不明时温控状态标记为未知
- 检验机构可核对完整来源，案件人员可追溯任一单盒任意时点的保管人、开封原因和剩余数量

## 本地校验

运行项目自带测试即可确认样例资料可读取，且领域标识与版本字段完整。所有示例均为虚构数据，不含真实个人信息、账号或访问凭据。
